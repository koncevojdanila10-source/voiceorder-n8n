# Настройка

Импортируйте VoiceOrder.json отдельно. Рабочие workflows автора не затрагиваются. Не запускайте два Telegram Trigger на одном боте.

## Подключения и доступ

Создайте Telegram API credential для отдельного бота и OpenAI API credential. Выберите Telegram credential во ВСЕХ узлах Telegram/Telegram Trigger, OpenAI — в «Модель заказа» и «Распознать заказ». В публичном файле credentials отсутствуют. Не вводите токены в код.

В «Настройки VoiceOrder» заполните allowedChatIds — разрешённые ID личных чатов через запятую; botId — цифровой ID ВАШЕГО бота, не токен и не @имя. Без botId цитаты его сообщений не привязываются к уточнению. Группы, боты и неразрешённые пользователи запрещены.

Проверьте доступность выбранной модели (gpt-5.4-mini в исходном демо) и аудиораспознавания в своём аккаунте. При необходимости выберите доступную модель вручную. Используются штатные версии узлов из JSON: Code 2, Data Table 1.1, AI Agent 3.1 и другие. До активации проверьте совместимость вашей установки.

## Хранилище

Создайте пустую Data Table по orders-table.schema.json. Это описание колонок, НЕ файл для автоматического импорта строк. Системные id/createdAt/updatedAt создаёт n8n.

Выберите её вместо REPLACE_WITH_ORDERS_TABLE_ID во всех семи узлах:

1. Сохранить демо-черновик
2. Привязать сообщение
3. Подтвердить или отменить однократно
4. Найти незавершённое уточнение
5. Сохранить вопрос и контекст
6. Привязать вопрос к сообщению
7. Закрыть прежние уточнения

Черновики и уточнения действуют 24 часа. Confirmed/cancelled не редактируются. Готовый черновик с кнопками для изменения сначала отмените, затем отправьте полный заказ. Уточняемый заказ можно исправлять короткими ответами. Данные автоматически не удаляются; нужна политика хранения.

## Проверка

`node --test core.test.cjs` — локально, без внешних вызовов. Ручной вход «Проверка без Telegram» использует настоящую AI-модель и читает таблицу, но в штатном dryRun не пишет заказы/не отправляет Telegram. AI может тарифицироваться. Успешный статус исполнения не заменяет passed=true у всех результатов.

После настройки активируйте копию. Проверьте /start, /catalog, текст, голос, итог 6450 ₸, неизвестный товар, чай без типа, воду 17 бутылок, блок с явным размером, короткий ответ на вопрос, «Да», «Новый заказ», отмену/подтверждение и повторное нажатие. При ошибке проверьте журнал перед повтором: запись могла сохраниться без доставки ответа.
