# VoiceOrder — голос → черновик заказа

Демо Telegram-бот на n8n: голосовое, аудиофайл или текст → товары и количество → сопоставление с каталогом → расчёт → проверка и подтверждение кнопкой в Telegram.

## Что умеет

- Считает цены только по каталогу, не по ответу AI.
- Поддерживает русские и казахские алиасы; качество проверяйте на своих примерах.
- Понимает разговорные размеры: «100 граммовый», «литровая» и эквивалентные граммы/килограммы.
- Пересчитывает физические количества только по явно заданному packSize, без округления.
- Считает блоки только с явно указанным количеством бутылок/упаковок внутри.
- Не подменяет неизвестные размеры, бренды и товары.
- Сохраняет позиции при конкретном коротком ответе на уточнение. «Да» не выбирает варианты и не подтверждает заказ. «Новый заказ» сбрасывает контекст.
- Привязывает подтверждение к чату, сообщению и сроку; повторное нажатие не подтверждает запись снова.

## Быстрый старт

1. Импортируйте [VoiceOrder.json](VoiceOrder.json) как отдельный новый workflow.
2. Настройте свои подключения, доступ и отдельную таблицу по [SETUP.md](SETUP.md).
3. Выполните `node --test core.test.cjs`, затем проверьте голос и текст в Telegram.

Пример: «Две упаковки кофе и три упаковки сахара» → 2 × 2400 + 3 × 550 = 6450 ₸ по демо-каталогу.

## Статус

38 узлов, 34 локальные проверки. В настроенном авторском демо отдельно проверены голос, текст, уточнения и кнопки. Три последних целевых AI-примера прошли; полный набор после последней правки целиком не прогонялся. Публичный импорт с вашими credentials требует самостоятельной проверки.

Это демо, а не готовый магазин: товары/цены вымышленные, нет оплаты, резервирования и отправки поставщику. Кофе 200 г отсутствует (есть 250 г), размер блока не угадывается. Возможны ошибки внешнего AI-сервиса. Для реального запуска нужен уникальный ключ входящего события: повторная доставка Telegram update может создать два черновика.

Публичная копия выключена, доступ закрыт. Токены, реальные chat ID, credentials, таблицы и журналы исключены. Текст/аудио передаются OpenAI, API может тарифицироваться. См. [SECURITY.md](SECURITY.md). Лицензия пока не выбрана.
