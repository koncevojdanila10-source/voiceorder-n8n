# Безопасность

- Не публикуйте токены Telegram/OpenAI, credentials, chat ID, заказы клиентов или историю выполнений.
- В шаблоне credentials отсутствуют, allowedChatIds/botId пусты, таблица — заглушка, workflow выключен. Тестовые цифровые ID вымышленные.
- Текст/аудио передаются внешнему AI-сервису; используйте вымышленные данные в демо.
- Для реального магазина нужны свой каталог, разграничение доступа, согласие клиентов/политика хранения, уникальный ключ Telegram update, мониторинг и резервные копии. Оплата/поставщики требуют отдельной интеграции.
- Подтверждение кнопкой меняет статус демо-записи, но не является оплатой или юридическим обязательством.
- Изменение таблицы и доставка Telegram — разные операции. При ошибке не повторяйте заказ без проверки журнала.
- Если секрет уже опубликован или отправлен в чат, смените его у провайдера и обновите credential. Удаление текста не отзывает секрет.
